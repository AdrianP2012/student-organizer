# StudentHub — Student Organizer

A simple student organizer built with HTML, CSS and vanilla JavaScript.

## Features in this starter version
- Dashboard with task counts and upcoming tasks
- Add homework/tasks with a subject and due date
- Mark tasks as completed
- Delete tasks
- Filter all, to-do and completed tasks
- Sample weekly timetable
- Saves tasks in the current browser using `localStorage`
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a **new public repository** named `student-organizer`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the **root** of the `main` branch.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. The Pages screen will show the live website URL.

The project repository and the published website are separate things: the repository stores the code, while GitHub Pages serves the website.

## Important privacy note
This starter stores tasks only in the browser that created them. It does not have accounts or cloud syncing. Do not add private student information, passwords, grades, or other sensitive data to a public repository or shared demo.
